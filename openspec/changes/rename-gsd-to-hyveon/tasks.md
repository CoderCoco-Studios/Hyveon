- [x] 7.2 **Generated parent-repo `Makefile` legacy fallback:** `scripts/init-parent.ts`'s `renderMakefile()` template resolves `PARENT_TFVARS_MARKER`/`TFVARS_MARKER` to the new `.hyveon` path if present, else the legacy `.gsd` path if *that's* present, else the new path — so an already-scaffolded parent repo (whose Makefile is not regenerated by updating the submodule) keeps working without requiring the `mv .gsd .hyveon` migration step.
