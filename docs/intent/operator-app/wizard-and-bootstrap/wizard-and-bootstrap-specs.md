- [x] **APP-WIZARD-GATE-002**: When the app launches and electron-store `wizardCompleted` is `true`, the renderer shall open the dashboard directly without showing the wizard (`app.component.tsx:40-54,89`). (OpenSpec: wizard-flow / Wizard launch gating)

(OpenSpec: wizard-flow / Wizard launch gating) (gap: `wizard.controller.ts:168,217-219` falls back to `HYVEON_TEST_MODE === '1'` in the production read path)
